# sitecomply.ca

Static website for SiteComply, hosted on GitHub Pages at https://sitecomply.ca.

- Edit content in `_src/build.py`, then run `python3 _src/build.py` to regenerate the HTML pages.
- Styles: `assets/styles.css`. Scripts: `assets/main.js`.
- Forms post to FormSubmit and are delivered to matt@sitecomply.ca.
